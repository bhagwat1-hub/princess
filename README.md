# Princess Day — Riya ♡

A responsive, static Princess Day surprise website made with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser. No installation or backend is needed.

## Deploy on GitHub Pages
1. Create a public GitHub repository (for example `princess-day`).
2. Upload `index.html`, `style.css`, `script.js`, the `assets` folder and this README.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then Save.
6. Wait for the Pages deployment. Your link will look like:
   `https://YOUR-USERNAME.github.io/princess-day/`

## Personal photos
The four supplied photos are already included in `assets/`. To replace one, keep the same filename or update its path in `index.html`.

## Music
Tap the music control in the top-right corner. It plays a soft, original ambient tone generated in the browser (no external music download required). Browsers require a user tap before audio can start.
